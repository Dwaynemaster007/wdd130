# WDD 130: Web Fundamentals

HTML and CSS coursework for **WDD 130 at BYU-Idaho** by Thubelihle Dlamini. The main project is **WildWater Adventures**, a multi-page website for a white-water rafting company.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## Projects

### 🛶 WildWater Adventures ([`wwr/`](wwr/))

A complete small-business site with four pages: [Home](wwr/index.html), [About](wwr/about.html), [Trips](wwr/trips.html) and [Contact](wwr/contact.html). It uses semantic HTML, a shared stylesheet, a Flexbox navigation bar, a trips table and a contact form.

| Week | Topics | Files |
| --- | --- | --- |
| 01 | Page structure, file paths, images | [`first-page`](week01/first-page.html), [`favorite-city`](week01/favorite-city.html) (Manzini), [`file-paths`](week01/file-paths.html), [`images`](week01/images.html) |
| 02 | Block vs inline, the box model, basic layout | [`block-vs-inline`](week02/block-vs-inline.html), [`box-model`](week02/box-model.html), [`basic-layout`](week02/basic-layout.html), [`temple`](week02/temple.html) |
| 03 | Classes and IDs, floats, positioning | [`class-and-id`](week03/class-and-id.html), [`float`](week03/float.html), [`overlay`](week03/overlay.html) |
| 04 | Flexbox layouts and navigation | [`flexbox-layout`](week04/flexbox-layout.html), [`flexbox-menu`](week04/flexbox-menu.html), [`header-layout`](week04/header-layout.html), [`layout-exercises`](week04/layout-exercises.html) |
| 05 | Tables and forms | [`table`](week05/table.html), [`poll-form`](week05/poll-form.html), [`quiz`](week05/quiz.html) |

The [course home page](index.html) links to everything.

## Run locally

It's all static HTML and CSS, so there's nothing to install. Clone it and open `index.html` in a browser:

```bash
git clone https://github.com/Dwaynemaster007/wdd130.git
```
